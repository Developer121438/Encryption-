# 🔐 File Encryption & Decryption App

A browser-based file encryption and decryption application built with **HTML, CSS, and JavaScript**. The app allows users to select files, protect them with a password, encrypt or decrypt them, and download the processed files.

## 🌐 Live Demo
https://developer121438.github.io/Encryption/

> Replace `#` with your GitHub Pages URL after deploying the project.

## ✨ Features

* 🔒 Encrypt files with a password
* 🔓 Decrypt encrypted files
* 📁 Select files directly from the browser
* 📊 Visual progress indicator
* ⬇️ Download processed files
* 🔑 Password-protected processing
* 📱 Responsive user interface
* 🎨 Clean and simple design

## 🛠️ Technologies Used

* **HTML5** — Structure and file input
* **CSS3** — Styling, layout, animations, and responsive design
* **JavaScript** — File handling, encryption/decryption logic, progress tracking, and downloads

## 🚀 How to Use

1. Open the application in your browser.
2. Select a file you want to process.
3. Enter a password.
4. Choose **Encrypt** or **Decrypt**.
5. Wait for the process to complete.
6. Download the resulting file.

## 🎯 Project Purpose

This project was created to practice practical front-end development concepts, including **file handling, client-side processing, JavaScript interactions, progress indicators, and security-focused functionality**.

## ⚠️ Important Note

This project is primarily an educational front-end project. It demonstrates encryption-related concepts in a browser environment and should not be considered a replacement for professionally audited encryption software for highly sensitive data.
